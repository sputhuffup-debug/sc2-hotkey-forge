# SC2 Hotkey Forge

A single-page editor for StarCraft II `.SC2Hotkeys` profiles: visual keyboard, modifier
layers, rebinding by keypress, rapid-fire (TargetChoose) toggles, import/export.

Open `index.html` locally or serve it with GitHub Pages. `LeftHand AllRaces.SC2Hotkeys`
is the bundled example profile (left-hand layout, cameras on Q/W/E, army groups on `–5).
